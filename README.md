# Margin Lab

Margin Lab takes the sales from a café's till and shows, for every drink, what is left after tax and purchasing. Plus what a price change does and whether the month adds up.

**[juliokoelle.github.io/margin-lab-site](https://juliokoelle.github.io/margin-lab-site/)**

- Live with a real café as beta user since September 2026
- Daily sales via ready2order, other tills via CSV export
- This repository holds the landing page only. The app itself is private.

Built by Julio Koelle with Claude Code.
